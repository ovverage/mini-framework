# Mini Framework

Небольшой PHP-фреймворк

## Цель проекта

Реализовать минимальное ядро веб-фреймворка и на практике изучить обработку HTTP-запросов, маршрутизацию, архитектуру MVC и взаимодействие компонентов через понятные интерфейсы.

## Статус

Пока все планируется.

## План разработки

- [ ] Разобраться с автозагрузчиком.
- [ ] Реализовать единую точку входа и запуск приложения.
- [ ] Добавить классы HTTP-запроса и ответа.
- [ ] Реализовать маршрутизацию и параметры маршрутов.
- [ ] Добавить контроллеры и базовую структуру MVC.
- [ ] Реализовать контейнер зависимостей.
- [ ] Добавить middleware для обработки запросов.
- [ ] Настроить конфигурацию и переменные окружения.
- [ ] Добавить вывод представлений.
- [ ] Реализовать базовую работу с базой данных через PDO.
- [ ] ...

## Технологии

Планируется использовать PHP, Composer и PDO. Поддерживаемая версия PHP, зависимости и инструкции по запуску будут указаны после реализации базового ядра.

## Подход к разработке

- ООП архитектура и разделение ответственности.
- Небольшие компоненты с понятными интерфейсами.
- Постепенное развитие от обработки простого запроса до демонстрационного приложения.

## Доступ к репозиторию

Репозиторий публичный, поэтому его можно просматривать и клонировать. Прямое внесение изменений доступно только владельцу и пользователям, которым он явно предоставит права записи. Pull request сам по себе не изменяет код в репозитории: для этого требуется слияние пользователем с соответствующими правами.
